# Scaffold the application and prove Docker deployment and restoration

## Outcome

Create the smallest reproducible application on the existing VPS, with a recovery procedure that has been exercised.

## Scope

- [ ] Confirm stack choice, VPS resources, operating system, domain, reverse proxy, and backup destination.
- [ ] Add Django and PostgreSQL with locked dependencies, Dockerfile, compose.yaml, and placeholder-only .env.example.
- [ ] Configure health checks, private database networking, TLS integration, secure sessions, and production settings.
- [ ] Add actual development, test, and migration commands to README and AGENTS.md.
- [ ] Add CI for the application and configure private vulnerability reporting.
- [ ] Document updates, controlled migrations, encrypted off-host backups, and rollback.
- [ ] Restore a backup into an isolated instance and measure recovery.

## Acceptance criteria

- [ ] A clean checkout starts with documented commands and no embedded secrets.
- [ ] Only intended proxy ports are publicly reachable.
- [ ] Database and approved media survive container replacement.
- [ ] An isolated restore recovers representative records and media.

## Dependencies

Can start independently.

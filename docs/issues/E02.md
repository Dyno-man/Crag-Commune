# Audit data rights and assemble a reviewed pilot catalog

## Outcome

Establish a legal and maintainable source of useful climb facts before building route recommendations.

## Scope

- [ ] Audit a sample of current OpenBeta coverage and retain field-level provenance.
- [ ] Complete the source register, including storage, display, model processing, map derivatives, and export rights.
- [ ] Document permission requirements for any supplied PDFs; keep restricted originals private.
- [ ] Collect original observations where permitted sources are incomplete.
- [ ] Review 30 to 60 candidate climbs with stable IDs, discipline-specific grades, aliases, and uncertainty.
- [ ] Define import dry runs, duplicate resolution, revisions, withdrawal, and cache invalidation.

## Acceptance criteria

- [ ] Every published field has approved provenance and permitted intended uses.
- [ ] No Mountain Project scrape, unlicensed PDF content, or restricted photos enter the repository.
- [ ] The pack contains relevant warmups and projects for the pilot group.
- [ ] Unknown coordinates and disputed grades remain explicit rather than guessed.

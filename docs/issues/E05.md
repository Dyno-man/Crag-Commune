# Add discussion moderation and member privacy controls

## Outcome

Keep a small local forum usable without relying on real-name verification or automated skill ratings.

## Scope

- [ ] Add the four initial discussion categories and replies with safe rendering.
- [ ] Implement report, block, removal, suspension, and moderation audit records.
- [ ] Define contribution terms, privacy notice, proposed age policy, deletion behavior, and log retention.
- [ ] Add abuse limits for signup, login, posts, uploads, and expensive endpoints.
- [ ] Assign moderation coverage and escalation for sensitive access reports.
- [ ] Keep member content outside public dataset exports and model context.

## Acceptance criteria

- [ ] A moderator can handle a report and audit the action.
- [ ] Blocking and visibility are enforced server-side.
- [ ] Malicious HTML and oversized content are rejected or rendered safely.
- [ ] The deletion and backup-retention behavior matches the published notice.

Backlog E03, Backlog E04

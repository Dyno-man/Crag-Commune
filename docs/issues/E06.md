# Build and field-check the deterministic planner and map exports

## Outcome

Produce a useful warmup-to-project itinerary and PNG without any model call or paid map dependency.

## Scope

- [ ] Create area, feature, climb, source, access, and trail-graph models with review states.
- [ ] Implement contextual name and alias resolution and discipline-specific grade ordering.
- [ ] Filter closures and unsupported records before scoring candidate itineraries.
- [ ] Respect a fixed project, editable time budget, walking preferences, and a return path.
- [ ] Require reviewed trail edges for every navigable leg; fail usefully on disconnection.
- [ ] Render an original SVG-to-PNG map or explicitly non-scale schematic with sources, dates, stop labels, and current-plan link.
- [ ] Version saved plans and invalidate dependent caches when access or permission changes.
- [ ] Have two local reviewers independently check paths and stop identification.

## Acceptance criteria

- [ ] Form-based planning works with no model credentials.
- [ ] Every selected climb and trail edge belongs to the approved pack and meets hard constraints.
- [ ] Closed or revoked records never appear as eligible stops.
- [ ] Phone-readable exports match the saved plan and exclude unauthorized private details.
- [ ] Field review resolves ambiguous junctions before navigable coverage is advertised.

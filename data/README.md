# Catalog source register

No climbing dataset is bundled yet. Audit a 30-to-60-climb pilot pack before building a broad importer. All proposed fields below are required to be considered; an unknown value is an explicit unresolved review item.

## Source record template

- Internal source ID and source title
- Owner or licensor and source URL
- Dataset version or content hash; retrieval date
- License identifier or private permission-evidence reference
- Covered regions, assets, and fields
- Storage, public display, derivative-map, export, and model-processing permissions
- Required credit and license link
- Expiration, withdrawal conditions, and contact method
- Import batch, reviewer, and review date
- Status: pending, approved, restricted, withdrawn

## Field evidence template

- Entity ID and field name
- Asserted value and source record ID
- Source location such as page number or provider ID
- Coordinate precision and represented object, if applicable
- Date observed and date checked
- Reviewer and state: proposed, reviewed, published, disputed, withdrawn
- Superseded assertion and reason for change

Never put private emails, licensed raw guides, or production user data in this folder. Application fixtures must be clearly fictional or independently approved for redistribution.
